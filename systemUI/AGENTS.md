# 商城用户端接续说明

> 当前基线：3.0.0 / V007。商城通过 `/api/auth` 代理直连若依 `/captchaImage`、`/register`、`/login`、`/getInfo`、`/logout`；代理去掉 `/api/auth`。默认注册角色 common，无后台权限；管理员可登录商城。业务仍走 `/api/mall`，令牌仅 Pinia 内存。邮箱码及邮箱找回不启用，旧独立认证和 29 操作描述只作历史记录。真实联调默认验证统一认证与权限，详情见 `../docs/api/若依统一认证.md`。

本目录是独立 Vue 3 工程。通常只修改本目录；用户明确要求认证、权限或共享接口变更时应同步后端、管理端和契约。
