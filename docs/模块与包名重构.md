# 后端模块与 Java 包名重构

2026-10-23 按用户要求完成。Maven 父工程改为 `com.gc:gc:3.9.2`，所有自有 Java 源码、测试和生成模板使用 `com.gc` 前缀。

| 原模块 | 当前模块 / artifactId |
| --- | --- |
| ruoyi-admin | gc-admin |
| ruoyi-common | gc-common |
| ruoyi-framework | gc-framework |

| ruoyi-quartz | gc-quartz |
| ruoyi-system | gc-system |
| gameshop | gc-shop |

商城业务 Java 包为 `com.gc.gameshop`；`gc-shop` 是 Maven 模块名，连字符不能用于 Java 包名。Mapper XML、MyBatis/Spring 扫描范围、日志配置、验证码反射类名、任务白名单、生成器默认包、模板 import、测试及文档路径均已同步。

## 启动与 IDE

从 `system` 目录运行：

```powershell
.\mvnw.cmd -B clean package
.\start.ps1
```

- 可执行文件：`gc-admin/target/gc-admin.jar`。
- 启动类：`com.gc.RuoYiApplication`；IDE 工作目录设为 `system`，重新加载 `system/pom.xml`。
- `bin/run.bat` 复用 `start.ps1`。`ry.bat`、`ry.sh` 使用新 jar 路径和 `system` 工作目录，并移除已不支持的旧 JVM 参数。Unix 脚本与 Maven Wrapper 固定 LF 换行。
- Java 源码目标版本仍为 17。本机本次构建与真实运行使用 JDK 21.0.2；未在 Linux 主机执行部署。

## 现有数据和会话

本次无需新增 SQL 迁移。表名、账号、角色、交易归属、接口 URL、菜单路由、配置环境变量和 Quartz 的 `gameshopOrderExpiry.closeExpired()` Bean 入口保持兼容。根目录 `sql/` 的完整快照、图片包和校验文件没有改写。

Redis 序列化器在读取类型标记时，将历史 `com.ruoyi.*` 映射到 `com.gc.*`，随后仍通过当前包白名单解析。业务字符串不做替换，新写入缓存使用新类型名。兼容范围覆盖旧登录会话及字典缓存；认证仍核验账号状态和凭证指纹。无需清空 Redis，也不放宽后台权限。

上游许可证、源码作者与来源说明保留。`ruoyi` 运行配置前缀和原生认证的命名保持兼容，不能将这些字符串误当成漏改的 Java 包路径。
