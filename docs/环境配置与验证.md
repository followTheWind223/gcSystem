## 后端配置

`system/.env.example` 是模板，复制为 `system/.env` 后填写本机连接信息与密钥。当前本机文件已创建，数据库信息由使用者填写，JWT 密钥独立随机生成。该文件已验证被 Git 忽略，不能添加到版本控制。

Spring 使用 `spring.config.import=optional:file:./.env[.properties]` 读取文件，因此必须从 `system` 工作目录启动；IDE Working directory 同样设为 `system`。这是 **Java properties** 语法：不加包裹引号，Windows 路径用 `/`；反斜线等特殊字符遵循 properties 转义规则。进程环境变量优先于文件，可由部署环境直接注入。

| 环境 | 行为 |
| --- | --- |
| `dev`（默认） | DB/Redis/密钥读取 `.env` 或环境变量，允许本地 API 文档 |
| `test` | 必须显式指定 `TEST_DB_URL`、`TEST_DB_USERNAME`、`TEST_DB_PASSWORD`、`TEST_REDIS_DATABASE`，避免误用开发库 |
| `prod` | 必须指定完整 `DB_URL` 与数据库凭证，关闭热重启和 API 文档；不复制本地开发 `.env` |

`DB_URL` 可以覆盖按 `DB_HOST/DB_PORT/DB_NAME` 组装的地址。MySQL 8 在本机无 TLS 连接时可按需设置 `DB_ALLOW_PUBLIC_KEY_RETRIEVAL=true`；生产使用有效证书和经过校验的 TLS URL。Redis 连接变量为 `REDIS_HOST/PORT/DATABASE/PASSWORD`。

若依 JWT 使用 HS512，`TOKEN_SECRET` 设置为至少 64 字节随机数据的 Base64 值。生成示例（自行将生成结果填入私密文件，不写进文档或提交）：

```powershell
$tokenBytes = New-Object byte[] 64
$generator = [Security.Cryptography.RandomNumberGenerator]::Create()
$generator.GetBytes($tokenBytes)
[Convert]::ToBase64String($tokenBytes)
$generator.Dispose()
```

`UPLOAD_PATH`、`LOG_PATH` 可调整文件位置；默认相对目录便于跨系统使用。Druid 监控控制台默认关闭，已移除上游演示控制台凭据。

## 管理端与部署

- `.env.development`、`.env.production`、`.env.staging` 仅含公开配置，均使用 `VITE_APP_BASE_API=/admin-api`。
- `.env.local` 用于本机覆盖；`DEV_PROXY_TARGET`、`DEV_HOST`、`DEV_PORT` 只供 Vite 使用。默认监听回环地址，5174 被占用时直接报错。

- 本次未执行任何依赖安装脚本；构建通过说明当前平台所需的 esbuild、Sass、Rollup 原生依赖已通过包文件就绪。其他操作系统仍需单独验证。
