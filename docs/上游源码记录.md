## 导入后的修改

- 工程目录采用 `system`、`adminsystemui`；商城占位目录现为 `systemUI`（原 `gsSystemUI`），接口交接按当前目录维护。
- 后端保留六个若依代码模块及父 POM；Maven Wrapper 3.3.4 下载固定 Maven 3.9.10，编译使用 Java `release 17`。
- 2026-10-23 按用户指令，六个模块改为 `gc-*`，商城模块改为 `gc-shop`，父 POM 为 `com.gc:gc`，Java 包前缀为 `com.gc`。同步配置、Mapper、生成模板、启动脚本，保留源码版权与许可证；详见 [重构说明](./模块与包名重构.md)。
- 数据库、Redis、JWT、文件目录与日志路径使用外置属性；增加 `dev/test/prod` 配置，默认不开放 Druid 控制台。
- `logback.xml` 改为 `logback-spring.xml`，日志路径读取 Spring 配置。
- 原始 SQL 移至 `system/sql/upstream`，内容不改，增加首次建库示例和执行顺序说明。
- 管理端固定 Node/npm 和 npm 锁文件，禁止依赖自动安装脚本，缓存放入项目忽略目录。
- 管理端端口 5174，代理前缀统一 `/admin-api`，增加同语义的 Nginx 示例。
- 在上游主版本内更新 Axios 1.20.0、js-cookie 3.0.8、Vue 3.5.44 和 Vite 6.4.5。核对的官方发布记录：[Axios](https://github.com/axios/axios/releases/tag/v1.20.0)、[js-cookie](https://github.com/js-cookie/js-cookie/releases/tag/v3.0.8)、[Vue](https://github.com/vuejs/core/releases/tag/v3.5.44)、[Vite](https://github.com/vitejs/vite/releases/tag/v6.4.5)。最终审计及保留项见环境验证文档。

后续已新增独立 `gc-shop` 业务模块、15 张商城及迁移表、会员独立认证链和七个后台业务页面，详见[验收记录](./后端与后台验收.md)。

2026-10-22 管理端展示改为游戏道具商城：重建工作台、登录/注册品牌区与 SVG 标识，移除官网/源码/文档宣传入口、捐赠及上游更新记录，替换默认头像、页脚与默认公告。V004 只精确调整默认种子展示值。原始上游 SQL、两端 LICENSE、源码版权声明及本来源记录保留。
