# 接口字段与数据库映射

当前契约2.2.0、数据库V006；区服的新增字段、选择规则、完整JSON和兼容行为见[游戏区服管理与结算](./游戏区服管理与结算.md)。下方早期 serverName 请求示例仍作为旧客户端兼容示例，新客户端采用 serverIds。

数据库 V006，契约 2.2.0。直接列显示实际表列；关联/计算/Redis/上下文显示派生来源。生成字段与快照不可由前端直接覆盖。所有请求中的密码、验证码只在后端校验，不以明文落库或返回。
