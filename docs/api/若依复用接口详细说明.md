# 若依复用接口详细说明

**契约 2.1.0，数据库 V001。先读 [数据库字段字典](../database/字段字典.md)。** 本文件逐接口展开路径、查询、请求头、请求体、所有响应嵌套字段、数据来源和完整成功/失败 JSON。

商城接口及既有若依接口均标 implemented，验证范围见后端实施记录。JSON 均为完整合法示例，没有用省略号隐藏字段；各场景按其业务前提独立展示，不是按章节顺序执行。金额和新业务 ID 使用字符串；日期示例固定为 2026-10-22，Mock 应统一移动测试时钟。

字段表中的“必有”相对于直接父对象：父对象为 null 或可选父字段未发送时，不要求其子字段出现。数组的 [] 表示每个元素。新商城请求 DTO 拒绝未声明字段；响应中可选字段可以省略，必有且可空字段必须显式返回 null。若依复用对象按上游协议保留可扩展属性，新商城 DTO 按本契约固定。
