## 错误码

| errorCode | HTTP | 含义 |
| --- | --- | --- |
| `MALL_VALIDATION_FAILED` | 400 | 参数校验失败 |
| `MALL_EMAIL_CODE_INVALID` | 400 | 邮箱验证码错误、过期或已消费 |
| `MALL_OLD_PASSWORD_INVALID` | 400 | 原密码不正确 |
| `MALL_UNAUTHENTICATED` | 401 | 缺少、过期、被撤销或类型不匹配的令牌 |
| `MALL_INVALID_CREDENTIALS` | 401 | 账号、密码或账号状态不符合登录条件，统一提示 |
| `MALL_CAPTCHA_INVALID` | 400 | 图形验证码错误、过期或已消费 |
| `MALL_FORBIDDEN` | 403 | 后台账号缺少接口权限 |
| `MALL_RESOURCE_NOT_FOUND` | 404 | 资源不存在或不属于当前会员 |
| `MALL_PROP_NOT_FOUND` | 404 | 公开商品不存在、下架、删除或分类停用 |
| `MALL_REGISTRATION_REJECTED` | 409 | 用户名或邮箱不可用，统一提示 |
| `MALL_PROP_UNAVAILABLE` | 409 | 商品或分类不允许新购买 |
| `MALL_STOCK_INSUFFICIENT` | 409 | 库存不足 |
| `MALL_QUOTE_EXPIRED` | 409 | 报价凭据过期或不再有效 |
| `MALL_QUOTE_CHANGED` | 409 | 商品价格变化，需要重新预览并确认 |
| `MALL_CART_CHANGED` | 409 | 购物车数量或所选项目在预览后改变 |
| `MALL_CART_LIMIT_EXCEEDED` | 409 | 购物车不同商品数超过 100 |
| `MALL_QUANTITY_EXCEEDED` | 409 | 合并购物车后的数量超过 99 |
| `MALL_IDEMPOTENCY_CONFLICT` | 409 | 同一幂等键对应不同请求内容 |
| `MALL_ORDER_STATE_INVALID` | 409 | 当前订单状态不允许该动作 |
| `MALL_ORDER_EXPIRED` | 409 | 订单已到期，不能支付 |
| `MALL_REVIEW_NOT_ALLOWED` | 409 | 本人订单未完成或该明细不满足评价条件 |
| `MALL_REVIEW_ALREADY_EXISTS` | 409 | 该订单明细已经评价，含被隐藏的评价 |
| `MALL_CATEGORY_IN_USE` | 409 | 分类仍有关联的未删除商品 |
| `MALL_VERSION_CONFLICT` | 409 | 后台数据版本已改变，请重新读取 |
| `MALL_DUPLICATE_VALUE` | 409 | 分类名称等唯一业务字段重复 |
| `MALL_UPLOAD_TOO_LARGE` | 413 | 图片超过大小或像素限制 |
| `MALL_UPLOAD_TYPE_UNSUPPORTED` | 415 | 不支持的图片类型或内容不匹配 |
| `MALL_RATE_LIMITED` | 429 | 触发限流，请按 Retry-After 重试 |
| `MALL_MAIL_UNAVAILABLE` | 503 | 邮件通道未就绪；不能跳过验证 |
| `MALL_INTERNAL_ERROR` | 500 | 内部错误，保留通用提示，不返回堆栈或 SQL |

| `MALL_METHOD_NOT_ALLOWED` | 405 | 该资源不支持此 HTTP 方法 |
| `MALL_RESPONSE_TYPE_UNSUPPORTED` | 406 | 资源不能提供所要求的响应格式 |
| `MALL_CONTENT_TYPE_UNSUPPORTED` | 415 | 请求 Content-Type 不受支持 |

| `MALL_EMAIL_VERIFICATION_DISABLED` | 503 | 邮箱验证开关关闭，发码和邮箱找回不可用 |
